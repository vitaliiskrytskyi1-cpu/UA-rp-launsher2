UA RolePlay — сервер open.mp
==============================

ЗАПУСК
  Двічі клацніть start-server.bat.
  Windows запитає дозвіл для мережі — натисніть «Дозволити доступ»
  (поставте галочки і для приватних, і для публічних мереж).
  Вікно сервера не закривайте, поки граєте.

БАЗА ДАНИХ
  Окремо нічого ставити не треба. Акаунти зберігаються у файлі
  scriptfiles\uarp.db, він з'явиться сам після першого запуску.
  Робіть його копію, щоб не втратити акаунти.

АДМІНКА ДЛЯ СЕБЕ
  1. Зайдіть на сервер і зареєструйтесь.
  2. Введіть у чаті: /rcon login ПАРОЛЬ
     (пароль — у файлі config.json, рядок "password" у розділі "rcon")
  3. Введіть: /makeadmin ВАШ_ID 5
  Список адмін-команд: /ahelp

КОМАНДИ ГРАВЦЯ
  /menu /help /stats /gps /me /do /try /b /s /pm /pay /report
  /car /lock /e /work /quitjob
  Банк, біржа праці й автосалон відкриваються, коли стати на значок.
