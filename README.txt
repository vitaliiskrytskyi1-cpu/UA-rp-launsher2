=====================================================================
  UA RolePlay — лаунчер для Android
=====================================================================

ЩО ВМІЄ
  - Показує онлайн сервера, кількість гравців і пінг (оновлюється кожні 15 с).
  - Стрічка новин з вашого хостингу (news.json) — змінюєте без оновлення APK.
  - Ввід ніка з перевіркою RP-формату Ім'я_Прізвище, нік запам'ятовується.
  - Докачує ВАШІ файли сервера (HUD, скіни, звуки) за manifest.json,
    перевіряє кожен файл за SHA-256, качає лише змінені.
  - Перевіряє, чи встановлена GTA: San Andreas з Google Play, і веде туди.
  - Просить оновити сам лаунчер, коли виходить нова версія.
  - Кнопка «Грати» запускає ігровий клієнт і передає йому нік та IP сервера.
  - Кнопки Discord і Telegram.
  - Без сторонніх бібліотек, Android 8.0+, горизонтальний екран.

СТРУКТУРА
  app/src/main/java/ua/rp/launcher/
      Config.kt        <- УСІ НАЛАШТУВАННЯ: IP, порт, хостинг, пакет клієнта
      MainActivity.kt  екран лаунчера
      SampQuery.kt     запит онлайну по протоколу SA:MP (працює з open.mp)
      Net.kt           новини, маніфест, завантаження файлів
      Updater.kt       оновлення файлів сервера
      GameLauncher.kt  перевірка GTA SA і запуск клієнта
  app/src/main/res/    вигляд, кольори, тексти, іконка
  hosting/             те, що викладається на хостинг
      news.json        новини
      make_manifest.py генерує manifest.json з папки files/
      files/           ваші файли сервера

---------------------------------------------------------------------
КРОК 1. НАЛАШТУВАННЯ
---------------------------------------------------------------------
  Відкрийте app/src/main/java/ua/rp/launcher/Config.kt і вкажіть:
    SERVER_HOST    — IP вашого сервера (не 127.0.0.1, а зовнішній IP хостингу/VPS)
    SERVER_PORT    — порт (зазвичай 7777)
    CDN_URL        — адреса, де лежатимуть news.json і manifest.json
    CLIENT_PACKAGE — назва пакета ігрового клієнта (див. крок 5).
                     Якщо змінюєте — змініть також у AndroidManifest.xml в <queries>.
    DISCORD_URL / TELEGRAM_URL — посилання або "" щоб сховати кнопку

  Назва застосунку під іконкою: app/src/main/res/values/strings.xml -> app_name
  Кольори: res/values/colors.xml (accent — жовтий колір кнопок)
  Іконка: res/drawable/ic_launcher_fg.xml (або File -> New -> Image Asset
          в Android Studio, щоб вставити свій логотип PNG)

---------------------------------------------------------------------
КРОК 2. ХОСТИНГ ДЛЯ НОВИН І ФАЙЛІВ (безкоштовно)
---------------------------------------------------------------------
  Найпростіше — GitHub Pages:
    1. Створіть репозиторій на github.com, наприклад uarp-cdn.
    2. Завантажте туди вміст папки hosting/ (news.json, manifest.json, files/).
    3. Settings -> Pages -> Branch: main -> Save.
    4. Адреса буде https://ВАШ_НІК.github.io/uarp-cdn/  — це і є CDN_URL.
  Або покладіть ці файли на свій VPS у папку веб-сервера (лише https).

  Оновили файли сервера:
    покладіть їх у hosting/files/, запустіть  python make_manifest.py
    і завантажте змінене на хостинг. Лаунчери самі докачають нове.

---------------------------------------------------------------------
КРОК 3. ЗБІРКА APK
---------------------------------------------------------------------
  1. Встановіть Android Studio (developer.android.com/studio).
  2. File -> Open -> оберіть папку UARPLauncher. Дочекайтеся Gradle Sync
     (перший раз качає компоненти, 5-15 хвилин).
     Якщо Studio запропонує оновити Gradle/AGP — можна погодитися.
  3. Перевірка на телефоні: увімкніть "Налагодження по USB", підключіть
     телефон і натисніть зелену кнопку Run.
  4. APK для гравців: Build -> Generate Signed App Bundle / APK -> APK ->
     Create new keystore (ЗБЕРЕЖІТЬ файл .jks і пароль — без них не
     випустите оновлення) -> release -> Create.
     Готовий файл: app/release/app-release.apk

  Нова версія лаунчера:
    збільште versionCode у app/build.gradle.kts і LAUNCHER_VERSION у Config.kt,
    зберіть APK, викладіть його, а в make_manifest.py передайте
    --launcher-version 2 --launcher-url https://.../app-release.apk

---------------------------------------------------------------------
КРОК 4. ПЕРЕВІРКА ОНЛАЙНУ
---------------------------------------------------------------------
  Онлайн запитується по UDP на порт сервера (як у списку серверів SA:MP).
  Якщо пише "Сервер недоступний", хоча сервер працює:
    - перевірте, що на VPS відкритий UDP-порт 7777;
    - у config.json open.mp параметр "enable_query" має бути true.

---------------------------------------------------------------------
КРОК 5. ІГРОВИЙ КЛІЄНТ — ВАЖЛИВО
---------------------------------------------------------------------
  Лаунчер — це оболонка. Сама гра онлайн працює через клієнт SA:MP для
  Android (бібліотека, що підключає мобільну GTA SA до сервера).
  Лаунчер запускає клієнт і передає йому в Intent:
      "nick"      — нік гравця
      "host"      — IP сервера
      "port"      — порт
      "files_dir" — папка з вашими файлами сервера
  Клієнт має прочитати їх у своїй головній Activity, наприклад:
      val nick = intent.getStringExtra("nick")

  Обмеження Android 11+: інший застосунок не може читати папку лаунчера
  (Android/data/ua.rp.launcher/). Тому є два шляхи:
    А) (як в Arizona Mobile) вбудувати клієнт у цей же проєкт, тоді
       клієнт читає files_dir напряму. Рекомендовано.
    Б) окремий клієнт сам качає ресурси за тим же manifest.json.

  Готові клієнти SA:MP для Android мають різні ліцензії. Перш ніж
  ставити на чужий клієнт свою назву і роздавати гравцям, отримайте
  дозвіл автора.

  Файли самої GTA San Andreas лаунчер НЕ завантажує і не повинен:
  гра належить Rockstar Games. Гравець купує її в Google Play,
  а лаунчер лише перевіряє, що вона встановлена. make_manifest.py
  автоматично пропускає файли гри, якщо їх випадково покласти в files/.
